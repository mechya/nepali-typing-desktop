Download — free everywhere

Pick your device, install, then switch input method to start typing Nepali.

📱

iPhone, iPad & Mac

Add the Nepali keyboard in Settings → General → Keyboard, then tap 🌐 to switch.

Download on the App Store
🤖

Android

Install, enable the keyboard in Settings → Language & input, then switch with the 🌐 key.

Get it on Google Play
🪟

Windows 10 & 11

Run the installer, then switch with Win + Space.

⬇ Windows installer
🐧

Linux — Ubuntu & Fedora

An IBus input method. Enable in Settings → Keyboard → Input Sources, switch with Super + Space.

⬇ .deb · Ubuntu ⬇ .rpm · Fedora

Install on Linux: sudo apt install ./ibus-nepali_*.deb  ·  sudo dnf install ./ibus-nepali-*.rpm  ·  then ibus restart
