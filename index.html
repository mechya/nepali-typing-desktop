How to type — the whole scheme on one page

A few simple rules cover almost everything. Type any of these in the box above to see them work.

Capital letter = hard (retroflex) sound

Lowercase is the soft dental sound, Capital is the hard one.

tतTट thथThठ dदDड nनNण

Double the vowel to make it long

One letter is the short vowel, two letters the long one.

kaकkaaका kiकिkiiकी kuकुkuuकू kaiकैkauकौ

Three kinds of “s”

Add capitals for the other two sibilants.

saस Saश SAष

Conjuncts join by themselves

Just type the consonants next to each other.

namasteनमस्ते raamroराम्रो dhanyavaadधन्यवाद

Special letters

Shortcuts for the letters that aren't simple sounds.

Gyaanज्ञान Xetraक्षेत्र kRShiकृषि xaछ omॐ

Nasals, signs & numbers

q → ं · C → ँ · full stop → ।

saqsaarसंसार gaauCगाउँ .। 2025२०२५

Download — free everywhere

Pick your device, install, then switch input method to start typing Nepali.

📱

iPhone & iPad

  1. Install from the App Store.
  2. Settings → General → Keyboard → Keyboards → Add New Keyboard → कुञ्जीपाटी.
  3. Tap 🌐 on the keyboard to switch.
Download on the App Store
💻

Mac

  1. Download and open the installer — macOS asks for your password.
  2. Log out and back in when asked (macOS only finds new keyboards at login).
  3. System Settings → Keyboard → Input Sources → Edit… → + → Nepali → कुञ्जीपाटी.
⬇ Mac keyboard Companion app
🤖

Android

  1. Install from Google Play.
  2. Enable it in Settings → System → Keyboard (or Language & input).
  3. Switch with the 🌐 key.
Get it on Google Play
🪟

Windows 10 & 11

  1. Download the installer (.exe) from the latest release and run it.
  2. Switch with Win + Space.
⬇ Windows installer
🐧

Linux — Ubuntu & Fedora

  1. Install: sudo apt install ./ibus-nepali_*.deb or sudo dnf install ./ibus-nepali-*.rpm
  2. Run ibus restart, then add it in Settings → Keyboard → Input Sources.
  3. Switch with Super + Space.

Questions

The things people ask most.

Is it really free?

Yes. Every feature works for everyone, on every platform, with no ads and no account. An optional one-time purchase only turns off a once-a-day reminder.

Does it send what I type anywhere?

No. Everything — the conversion and the word suggestions — runs on your device. Nothing you type leaves it.

I installed it on my Mac but can't find it.

Log out and log back in first — macOS only looks for new keyboards at login. Then go to System Settings → Keyboard → Input Sources → Edit… → + and choose Nepali → कुञ्जीपाटी.

Why isn't the Mac keyboard in the Mac App Store?

macOS only loads keyboards from a system folder that App Store apps aren't allowed to write to. So the keyboard is a separate free download, signed and notarized by Apple. The App Store app is an optional companion.

How do I type ज्ञ, क्ष, ऋ or ँ?

Gy → ज्ञ, X → क्ष, R → ऋ (after a consonant: kR → कृ), C → ँ, q → ं. See How to type — and the key chart inside the app has everything.

Does it work in Word, Facebook, WhatsApp…?

Yes. It's a real system keyboard, so it types standard Unicode Nepali into any app or website.
