# Nepali Keyboard — Phonetic (Romanized)

**Type Nepali anywhere by spelling words the way they sound.**
You type `namaste` → you get `नमस्ते`. Works in any app — Word, Chrome, Notepad, chat, email — as a system-wide input method.

🌐 **Website / download:** https://mechya.github.io/nepali-typing-desktop/

🔗 **Installation video:** https://youtu.be/EVeZXYwqdI4?si=IZ0TT9Ys_fQYHxgb
---

## ✨ Features
- **Phonetic Romanized → Devanagari** — write Nepali using the English keyboard, no layout to memorize.
- **Works system-wide** — types directly into any application.
- **Live suggestions** — a candidate list helps you pick the right word.
- **On-screen key chart** — see the romanization mapping anytime, plus Emoji and Sticker tabs.
- **Emoji on suggestions** — matching emoji appear beside Nepali words as you type (opt-in).
- **Sign picker** — `q` / `Shift+Q` cycle the combining signs (halanta, rakar, anusvara, chandrabindu, reph, visarga).
- **Private by design** — runs fully on your device. No keystrokes, usage data, or personal information are sent anywhere.
